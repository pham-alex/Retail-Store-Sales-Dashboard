# Retail Customer Shopping Analysis – Power BI Dashboard

## Project Overview
This project uses Power BI to analyze customer shopping behavior and purchasing patterns using a retail customer shopping dataset. The dashboard provides insights into product purchases, discounts, payment preferences, seasonal shopping trends, customer demographics, and customer satisfaction.

The goal of this project is to identify patterns in customer behavior and understand the factors that influence shopping decisions.

## Dashboard Features

The dashboard includes interactive buttons that allow users to navigate between different visualizations:

- **All Types of Items Purchased:** Displays the different product categories and items purchased by customers.
- **Items Purchased Due to Discounts:** Analyzes purchases associated with discounts to explore how discounts relate to customer purchasing behavior.
- **Payment Methods Distribution:** Shows the distribution of payment methods, such as cash and card.
- **Items Purchased in Each Season:** Compares customer purchases across Spring, Summer, Autumn, and Winter.
- **Amount Spent by Gender:** Compares the total spending between male and female customers.
- **Customer Age Distribution:** Displays the age distribution of customers to identify the most common customer age groups.
- **Average Customer Rating:** Shows average product ratings to evaluate customer satisfaction.

## Dataset Information

The dataset contains customer and purchasing information, including:

| Column | Description |
|---|---|
| CustomerID | Unique customer identifier |
| Age | Customer's age |
| Gender | Customer's gender |
| Category | Product category |
| ItemPurchased | Specific item purchased |
| Amount | Total transaction amount |
| Season | Season of purchase |
| PaymentMethod | Payment method used |
| ItemRating | Customer rating of the purchased item |
| DiscountApplied(%) | Discount percentage applied |

## Tools & Technologies
- **Power BI:** Dashboard development and data visualization.
- **Power Query:** Data cleaning and transformation.
- **DAX:** Calculations and measures for analyzing customer data.

## Key Objectives
- Identify popular product categories and items.
- Explore the relationship between discounts and purchasing behavior.
- Understand customer payment preferences.
- Analyze seasonal purchasing patterns.
- Compare spending across customer demographics.
- Evaluate customer satisfaction through product ratings.

## Purpose
This project demonstrates the use of data analysis and visualization to transform retail customer data into meaningful insights that can help businesses better understand their customers and make informed decisions.
